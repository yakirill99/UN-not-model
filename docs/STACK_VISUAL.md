## 1. Принятый стек

| Слой | Инструмент | Пакет | Зачем |
|---|---|---|---|
| Статический UI | Tailwind CSS + shadcn/ui | `tailwindcss`, `shadcn/ui` (CLI копирует компоненты в репо) | Палитра, сетки, таблицы, диалоги. Каркас отлично генерируется ИИ |
| Микроанимации | Motion (ex-Framer Motion) | `framer-motion` | Декларативно, прямо в JSX: наведение, появление, счётчики, «бомба с замком» |
| Хореография | GSAP | `gsap` | Таймлайны на цепочки («конец хода», экран зала): метки, перекрытия, ручной scrub |
| Графики | ECharts | `echarts` + свой React-обёртка на `useRef` | Диаграммы рейтинга, динамика УЖ, экология; `geo`-карта и анимированные дуги из коробки |
| Готовые анимации | Lottie | `lottie-react` + AE-плагин Bodymovin | «Хлопушки» из After Effects: взрыв, запуск ракеты, интро |
| Иконки | Lucide (+ Phosphor как запасной) | `lucide-react` | Один монохромный стиль, убийца «нейрослопа»; Recraft — если нужен кастомный набор |
| Шрифты | Один гротеск UI + один дисплейный | Google Fonts self-host | Заголовки дисплейные, данные — табличные цифры (`font-variant-numeric: tabular-nums`) |

Отклонённые альтернативы: Rive (сильный, но второй редактор и конвейер ассетов — вернуться, если Lottie не хватит интерактивности), Spline/R3F+Blender (3D — оверкилл для v1), PixiJS (понадобится только если карта перерастёт ECharts).

## 2. Слои: что чем делать

**База (Tailwind + shadcn/ui).** Вся статика: карточки, таблицы, форма приказов. Сначала дизайн-токены (раздел 4), потом компоненты. Правило вайбкода: промптим каркас, ревьюим дифф, параметры правим руками.

**Motion — состояние и отклик.** Всё, что реагирует на данные и действия: появление блоков (`AnimatePresence`), счётчик бюджета (анимация числа), ховеры, «бомба с замком», тосты отклонённых приказов. Пружины дают живость без подбора кривых.

**GSAP — спектакль по расписанию.** Сцены с таймлайном: подведение итогов раунда (лента обновляется по очереди), экран зала/проектора, интро раунда. `timeline.addLabel()` + перекрытия — как монтажная линейка.

**ECharts — данные.** Столбчатая диаграмма средних УЖ (P1 из отзывов), линейные графики экологии и УЖ по раундам, донат бюджета. Бонус: серия `lines` с `effect.show: true` на `geo` — те самые «прилёты ракет», 80% референса CFR.

**Lottie — эффекты из AE.** Всё, что проще нарисовать, чем запрограммировать: взрыв города, разблокировка арсенала, обложка раунда.

## 4. Дизайн-токены

Источник истины — `tailwind.config.ts` (палитра, шрифты, радиусы) и `styles/motion.ts` (длительности и кривые):

```ts
// styles/motion.ts — единый словарь движения
export const durations = { instant: 0.12, fast: 0.2, normal: 0.32, slow: 0.48 };
export const easings = {
  standard: [0.2, 0, 0, 1],        // выход, без отскока
  entrance: [0, 0, 0.2, 1],        // появление
  exit: [0.4, 0, 1, 1],            // исчезание
};
export const spring = { type: "spring", stiffness: 300, damping: 14 };
```

Правила: тёмная тема — только переключателем (жалоба №14), светлая по умолчанию; один акцентный цвет (красный) только для угроз и разрушений; зелёный — для роста показателей.

## 5. Правила производительности и доступности

1. Анимируем только `transform` и `opacity` — остальное вызывает layout и роняет 60 fps.
2. SVG-элементы: `transform-box: fill-box` + `transform-origin` в CSS, иначе повороты едут.
3. `prefers-reduced-motion: reduce` — отключаем декоративное, оставляем смену состояний.
4. Лимит одновременных Lottie на экране: 2–3. Тяжёлые сцены — по требованию.
5. Тикер и счётчики не должны перехватывать фокус — `aria-live="polite"` для новостей.

## 6. Вайбкодинг-воркфлоу

1. **Промпт на каркас:** «React + framer-motion компонент StatTile: значение, дельта, тренд-стрелка, spring-появление» — ИИ генерирует файл целиком.
2. **Ревью диффа:** смотрим, что предложил ИИ; левые зависимости и inline-стили — наружу.
3. **Правка руками:** меняются только токены и параметры (`stiffness`, `duration`) — не логика.
4. **Итерация промптом:** «сделай появление на 20% медленнее, отскок слабее» — Motion декларативен, ИИ правит безопасно.
5. Lottie-JSON руками и промптом не редактируется никогда — только перерендер из AE.

## 7. Конвейер Lottie: After Effects в веб

1. В AE собирается сцена (замок, взрыв, ракета) — шейпы, без растра и видео.
2. Плагин **Bodymovin** (встроен в AE как расширение) экспортирует `.json`.
3. JSON кладётся в `frontend/src/assets/lottie/`, играет `<Lottie animationData={...} loop={false} onComplete={...} />`.
4. Ограничения: без expression-тяжёлых проектов, текст — кривыми, длительность 1–3 с.
5. Свойства: ИИ и промпты этот файл не ломают — контроль полностью у автора анимации.

## 8. Карта мира: три стадии

|---|---|---|

## 9. План внедрения в репозиторий

1. `pnpm add framer-motion gsap echarts lottie-react lucide-react`
2. Tailwind init + дизайн-токены (палитра «дипломатический синий + песочный», красный акцент угроз).
3. Общие компоненты: `StatTile`, `DeltaBadge`, `BarRating`, `Ticker` — пилот на карточке страны (P1 из FEEDBACK).
4. Экран «Сводка мира 2.0»: ECharts-диаграммы, города всех стран.
5. Карта (стадия 1) — после редизайна карточек.

## 10. Демо

`docs/demos/bomb-lock.html` — одна сцена «бомба с замком» в трёх реализациях: Motion, GSAP, CSS-ключевые кадры. Открывается в браузере двойным кликом, интернет нужен только для CDN-скриптов. Рядом в каждой панели — код для React-версии проекта.
