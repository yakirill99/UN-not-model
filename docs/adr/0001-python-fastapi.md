# 0001. Python + FastAPI для бэкенда

- **Статус:** принято
- **Дата:** 2026-09-28

## Контекст

Нужен бэкенд веб-игры, который одновременно станет основой для симуляций, аналитики, RL и LLM-агентов. Автор развивается в fullstack, DevOps/SRE и ML/DS. Рассматривались три стека: Python + FastAPI, Python + Django + HTMX, Go.

## Решение

Python 3.13 + FastAPI + SQLAlchemy 2.0 (async) + PostgreSQL; фронтенд — React + TypeScript.

## Последствия

- Один язык для веба, движка, симуляций и ML: движок напрямую используется в pandas, Optuna, Gymnasium, LLM-агентах.
- Два проекта (бэк и фронт) и два языка.
- Свойства «одного бинарника» Go достигаются минимальным неизменяемым контейнерным образом (ROADMAP, раздел 5).

## Рассмотренные альтернативы

- Django + HTMX — быстрее до MVP, но слабее фронтенд и меньше гибкости API.
- Go — сильнее для SRE, но симуляции и ML потребовали бы моста в Python или дублирования логики.
