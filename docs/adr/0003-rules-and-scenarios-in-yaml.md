# 0003. Правила и сценарии — в версионированных YAML

- **Статус:** принято
- **Дата:** 2026-09-28

## Контекст

Баланс игры будет подбираться живыми партиями, симуляциями и Optuna. Числа, зашитые в код, делают это медленным. Кроме того, одни и те же правила нужно играть с разных стартов (исторический из Смольного, равный, случайный в симуляциях).

## Решение

- `rules/vX.yaml` — как устроен мир: цены, эффекты, лимиты, веса, порядок систем, модули. Поддерживается `extends` и переопределения. Валидируется Pydantic-моделью `RuleSet`.
- `scenarios/*.yaml` — стартовые условия: страны, города, развитие, бюджеты.
- Игра хранит версию правил, полный снимок параметров, сценарий и зерно.
- В YAML — только данные (числа, списки, флаги). Логика — в системах движка.

## Последствия

- Баланс меняется правкой конфига; старые партии переигрываются на своих правилах.
- Из `RuleSet` генерируются JSON Schema для фронтенда и LLM и таблицы документации.
- Риск превратить YAML в язык программирования — запрещено явно.
