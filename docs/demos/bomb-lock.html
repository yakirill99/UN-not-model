Одна сцена — три способа её оживить

«Бомба с замком» из отзывов: арсенал заблокирован — замок щёлкает, слетает, бомба просыпается. Ниже одна и та же анимация на Motion, GSAP и чистом CSS. В блоках кода — те же действия в React-версии для проекта. Полный код этой страницы — в исходнике (Ctrl+U), он же лежит в репозитории.

Сценарий: дужка открывается → замок улетает → бомба вздрагивает → пульс, фитиль горит.
Вариант 1

Motion · в React — пакет framer-motion

Заблокирована

Сила варианта: пружины из коробки (type: "spring") и то, что анимация привязана к состоянию, а не к кнопке. Идеален для данных и отклика.

// pnpm add framer-motion
import { motion } from "framer-motion";

// дужка: пружинный поворот, когда арсенал разблокирован
<motion.path
  d="M46 58 V48 A14 14 0 0 1 74 48 V58"
  style={{ transformBox: "fill-box", transformOrigin: "50% 0%" }}
  animate={{ rotate: unlocked ? -35 : 0 }}
  transition={{ type: "spring", stiffness: 300, damping: 12 }}
/>

// замок улетает
<motion.g
  animate={armed
    ? { x: 40, y: -60, scale: 0.8, opacity: 0 }
    : { x: 0, y: 0, scale: 1, opacity: 1 }}
  transition={{ duration: 0.5, ease: "easeIn" }}
> ... </motion.g>

// пульс боевой готовности
<motion.circle
  animate={armed ? { scale: [0.5, 2.2], opacity: [0.8, 0] } : {}}
  transition={{ duration: 0.9, ease: "easeOut" }}
/>
Вариант 2

GSAP · timeline как монтажная линейка

Заблокирована

Сила варианта: timeline с метками и перекрытиями — сцены «конца хода» и экрана зала собираются как монтаж. Пауза/scrub — бесплатно.

// pnpm add gsap
import gsap from "gsap";

const tl = gsap.timeline({ defaults: { ease: "power2.inOut" } });

tl.addLabel("unlock")
  .to(shackle, { rotation: -35, svgOrigin: "60 27", duration: 0.4 }, "unlock")
  .to(lock,    { x: 40, y: -60, scale: 0.8, opacity: 0, duration: 0.5 }, "unlock+=0.35")
  .to(bomb,    { keyframes: { rotate: [0, -3, 3, -2, 2, 0] }, duration: 0.5 }, "unlock+=0.6")
  .fromTo(glow, { opacity: 0, scale: 0.6 },
             { opacity: 0.9, scale: 1.4, duration: 0.8 }, "unlock+=0.8")
  .fromTo(ring, { opacity: 0.8, scale: 0.5 },
             { opacity: 0, scale: 2.2, duration: 0.9 }, "unlock+=0.95")
  .call(() => setArmed(true), [], "unlock+=1.6");

// React: рефки + useEffect, tl.pause()/tl.timeScale(2) — управление сценой
Вариант 3

Чистый CSS · ноль зависимостей, базовая линия

Заблокирована

Сила варианта: ноль JS, работает везде, идеален для тикера и ховеров. Слабое место: сложно синхронизировать с событиями — статусы гонит setTimeout.

/* transform-box: fill-box обязателен для SVG — см. стили выше */
@keyframes shackleOpen { to { transform: rotate(-35deg); } }
@keyframes lockFly    { to { transform: translate(40px, -60px) scale(.8); opacity: 0; } }
@keyframes bombShake  { 20% { transform: rotate(-3deg); } 40% { transform: rotate(3deg); }
                        60% { transform: rotate(-2deg); } 80% { transform: rotate(2deg); } }

.playing .c-shackle { animation: shackleOpen .4s ease-in-out forwards; }
.playing .c-lock    { animation: lockFly    .5s ease-in .35s forwards; }
.playing .c-bomb    { animation: bombShake  .5s ease-in-out .6s; }
.playing .c-glow    { animation: glowOn     .8s ease-out .8s forwards; }
.playing .c-ring    { animation: ringPulse  .9s ease-out .95s; }

/* React: класс от состояния */
<div className={playing ? "playing" : ""}>
  <svg> ... </svg>
</div>
Путь дизайнера

After Effects → Lottie · там, где рисовать проще, чем программировать

  • Сцена собирается в AE шейпами (замок, взрыв, запуск ракеты) — это твой родной инструмент.
  • Плагин Bodymovin экспортирует .json; файл кладётся в frontend/src/assets/lottie/.
  • JSON не редактируется ни промптом, ни руками — контроль полностью у автора анимации, ИИ его не ломает.
  • Применение: «хлопушки» 1–3 секунды — взрыв города, разблокировка арсенала, интро экрана зала.
// pnpm add lottie-react
import Lottie from "lottie-react";
import bombUnlock from "@/assets/lottie/bomb-unlock.json"; // AE -> Bodymovin

<Lottie
  animationData={bombUnlock}
  loop={false}
  onComplete={() => setArmed(true)}
/>
